## Important schema finding, verified from actual GeoJSON
Published features encode their SPB identifiers as **`properties.id`**, rather than `properties.place_id`. The canonical spreadsheet and research CSV convention remains `place_id`. Projection mapping must explicitly implement **`legacy place_id → GeoJSON properties.id`**; a naive `properties.place_id` validation would report four false missing records.

Actual published IDs: `SPB-PET-0001`, `SPB-PET-0002`, `SPB-PET-0003`, `SPB-PET-0011`. Both P1 and P2 restrict to exactly those four IDs; P3 has **no** production place ID (two provisional, intentionally unregistered external entity keys).

## Published media vs new P1 suggestion
The existing public GeoJSON **already links the same Commons images for 0002, 0003 and 0011**. For `0001`, `photo_url` is currently empty. Only `0001` would add a new image if later accepted, and no change has been made. Before publishing, compare published photo author/license captions with Commons file metadata and attribution requirements.
